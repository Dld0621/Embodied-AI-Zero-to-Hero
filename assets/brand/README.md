The repository uses a content-first editorial system built around readable hierarchy, technical precision, restrained color, and diagrams placed beside the principle they explain.

## Design principles

- **Editorial clarity:** one dominant message, moderate type scale, generous whitespace, and short supporting copy.
- **Technical precision:** explicit stages, thin connectors, numbered contracts, and evidence labels instead of decorative circuitry.
- **Flat hierarchy:** rules, spacing, and typography create hierarchy without glass effects, floating panels, or ornamental gradients.
- **Signal color:** blue identifies actions; semantic status colors are always paired with text labels.
- **Internationalization:** English and Chinese are independent layouts with the same information hierarchy, not text placed on a single shared image.
- **Accessibility:** system fonts, high contrast, descriptive SVG metadata, responsive layouts, keyboard focus, and reduced-motion support.

The `dof-logo*.svg` and `dof-hero*.svg` files are retained only as design-history references.
