# DoF Brand System

DoF stands for **Degrees of Freedom**: the controllable dimensions through which an embodied agent can perceive, reason, and act. The identity is intentionally minimal, international, and native to the repository.

## Visual language

- **Mark:** a D-shaped body with a central joint and three axes, expressing controllable degrees of freedom without borrowing another company's symbol.
- **Palette:** DoF Blue `#0A84FF`, Signal Blue `#4F7CFF`, Motion Violet `#8B5CF6`, Ink `#111827`, Slate `#64748B`, Canvas `#F7F8FC`.
- **Typography:** Inter or the operating system's native sans-serif stack; Noto Sans SC / Microsoft YaHei for Chinese.
- **Layout:** generous whitespace, one primary message per visual, restrained borders, rounded geometry, and no decorative noise.

## Usage

- Keep clear space around the mark equal to the center joint's diameter.
- Do not stretch, rotate, recolor, add shadows, or place text over the mark.
- Use the dedicated Chinese hero on Chinese pages; the DoF wordmark remains language-neutral.
- SVG is the source of truth so the identity stays sharp, accessible, and easy to maintain.
