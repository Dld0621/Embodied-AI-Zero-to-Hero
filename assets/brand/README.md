# Interface Visual System

The repository uses an original, international interface system built around editorial hierarchy, technical precision, spatial depth, and restrained signal color.

## Design principles

- **Editorial clarity:** one dominant message, generous whitespace, large type, and short supporting copy.
- **Technical precision:** explicit stages, thin connectors, numbered contracts, and evidence labels instead of decorative circuitry.
- **Spatial depth:** offset cards and soft tonal fields create hierarchy without glass-heavy effects or visual noise.
- **Signal color:** blue, cyan, violet, coral, and lime identify state changes; color never carries meaning alone.
- **Internationalization:** English and Chinese are independent layouts with the same information hierarchy, not text placed on a single shared image.
- **Accessibility:** system fonts, high contrast, descriptive SVG metadata, dark/light heroes, responsive documentation cards, and reduced-motion support.
