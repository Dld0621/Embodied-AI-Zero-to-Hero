# 从 Token 到 Attention：一步一步看数字变化

**2026-11-15 · 数值图解。** 先看[十个视角的 VLA 概念地图](31-vla-concept-map.md#axis-internals)。本页只拆开其中的“网络内部”，用三位置、单注意力头的小算例理解参数、特征、打分、mask 与输出。

## 1. 一张图片怎样变成一串向量？

以教学配置为例：224×224 的 RGB 图像分成 16×16 的不重叠 patch。一张图有 14×14 = 196 个 patch。每个 patch 含 16×16×3 = 768 个像素数值，再经线性投影得到宽度为 8 的向量。

```text
图片 [224,224,3]
  → 196 个小图块
  → 每块展平成 768 个数
  → 固定参数的线性投影 W[768,8] 与偏置 b[8]
  → 图像特征 [196,8]
```

这里 **196 是位置数量，8 是每个位置的特征宽度**。这个投影层有 768×8+8 = 6,152 个参数，不是 196 个参数。输入图片改变，输出特征改变；推理时通常仍使用同一组 W、b。

这遵循 [ViT 的 patch embedding 思路](https://arxiv.org/abs/2010.11929)，但尺寸 8 是特意缩小的教学选择。真实模型可能再加特殊 token、位置编码，进行裁剪、多相机编码、池化或 token 压缩。不能只看图片尺寸就断言最终序列一定长 196。

## 2. 把复杂图像缩成三个位置

下面用 A、B、C 三个位置和两个特征代替真实图像 token。它们不是“红杯”“蓝杯”“托盘”三个物体。一个物体的信息可能分布在许多 token 中。

$$
X=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}.
$$

固定模型参数：W_Q 和 W_K 是 2×2 单位矩阵，W_V 是对角元素为 1、2 的矩阵；这里没有偏置。矩阵乘法产生 Q、K、V：

$$
\begin{aligned}
Q&=XW_Q,\\
K&=XW_K,\\
V&=XW_V.
\end{aligned}
$$

因此 Q=K=X，而 V 的三行分别是 `[1,0]`、`[0,2]`、`[1,2]`。W 是训练学到或本例事先设定的**参数**；X、Q、K、V 是这次输入下计算的**特征/激活**。这里的相等来自刻意选用单位矩阵，真实网络的 Q、K 通常不同。

## 3. 一个 Query 怎样从其他位置读信息？

依照[原始 Transformer 的缩放点积注意力](https://arxiv.org/abs/1706.03762)，先计算每个 Query 和 Key 的打分。d_k 是 Key 的特征宽度，本例为 2。

$$
\begin{aligned}
S&=QK^\mathsf{T}/\sqrt{d_k},\\
P&=\operatorname{softmax}_{\mathrm{key}}(S),\\
O&=PV.
\end{aligned}
$$

这里 P 的行表示 Query，列表示 Key。沿每行归一化，表示这个 Query 从各 Key 位置读取 Value 的权重。Q/K/V 都是 `[3,2]`，S/P 是 `[3,3]`，输出 O 是 `[3,2]`。

拿第一行 Query A 手算：

| 项目 | 计算结果 | 含义 |
|---|---|---|
| 与 Key A/B/C 点积 | `[1,0,1]` | 相同 Query 与三个 Key 的打分 |
| 除以 √2 | 约 `[0.707,0,0.707]` | 缩放后的 logits，不是概率 |
| 沿 Key 做 softmax | 约 `[0.401,0.198,0.401]` | 有效位置权重之和为 1 |
| 汇总三个 Value | 约 `[0.802,1.198]` | 输出特征，不是机器人动作 |

注意力权重可以随输入变化，但 `W_Q/W_K/W_V` 仍保持不变。P 也不是“这个位置有物体的概率”，更不是模块贡献的因果证明。

## 4. 交互：先预测，再改变一个条件

交互在文档站加载。GitHub 或禁用脚本时，可以用上方表格复算默认值：Query A 权重约为 [0.401,0.198,0.401]，输出约为 [0.802,1.198]。启用因果 mask 后，Query A 只读取 A，权重为 [1,0,0]，输出为 [1,0]。
</div>

按顺序操作：

1. 保持默认输入，选择 Query B。先看它的 Q 与 A 有什么不同，再看权重分布。
2. 选择 Query A，勾选因果掩码。它现在只能读自己，不能读 B、C。
3. 保留因果掩码，选择 Query C。C 已经是最后一个位置，所以本例这一行的可见位置没有减少。
4. 取消掩码，把 A 的第一个输入特征改为 0。此时 Q_A 全零，三个打分相同，权重应为各 1/3。
5. 恢复默认，再改变输入。指出哪些 X、Q、K、V、P、O 数值变了，并解释为什么这不代表发生了参数训练。

这只是注意力子运算，没有输出投影、多头拼接、残差、Norm、位置编码或完整 VLA。它不模拟机器人任务性能。默认模型不含位置信息，非因果情况下同步重排位置会相应重排输出；因果 mask 会引入不同的位置可见性。

## 5. Mask 到底阻止了什么？

本例的因果 mask 只允许第 i 行读取 j≤i 的列。实现先把禁止位置排除在 softmax 外，再对允许位置归一化。**不是先把禁止打分置零**：零也可能在 softmax 后得到正权重。

| mask 名称 | 在哪里起作用？ | 本例是否实现？ |
|---|---|---|
| 注意力可见性 mask | 哪个 Query 可以读取哪个 Key | 实现了一个因果例子 |
| Key padding mask | 忽略填充输入位置 | 没有填充，因此未模拟 |
| Loss mask | 哪些监督元素计入损失 | 本例没有训练，不使用 |
| 图像分割 mask | 哪些像素属于目标/区域 | 本例不是图像分割 |

本组件内部的 `allowed=true` 表示可读取。框架 API 不一定相同：必须查当前函数文档，不能把同一布尔矩阵原样传到所有函数。例如 [PyTorch Transformer](https://docs.pytorch.org/docs/stable/generated/torch.nn.Transformer.html)和[缩放点积注意力 API](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.scaled_dot_product_attention.html)对布尔 mask 的含义有区别。

若所有 Key 都被禁止，就没有可归一化的有效项，不能把 NaN 当作有意义结果。本例的因果 mask 始终允许当前位置，所以不会出现整行禁读。

## 6. 把这个例子放回十个视角

| 在本页看到的东西 | 它属于哪种视角？ | 不要混成什么？ |
|---|---|---|
| Transformer 的注意力子模块 | 网络内部计算 | 完整 VLA、Agent 或控制器 |
| X、Q、K、V、P、O | 输入与中间表示 | 固定模型参数 |
| W_Q、W_K、W_V | 可学习参数；本例手工固定 | 当前输入的特征向量 |
| softmax、矩阵乘法 | 运算 | 软件框架或具体模型名称 |
| 因果 mask | 可见性设计 | 动作物理语义或评测规则 |
| 本地 JavaScript | 教学实现工具 | 一种新神经网络架构 |

继续理解“参数更新”：假设一个 8×8 线性权重 W 被冻结，LoRA 用 A[8,2] 和 B[2,8] 表示低秩增量。原矩阵仍有 64 个固定参数，新增 32 个可训练数值；不能说整个模型只剩 32 个参数，也不能据此断言训练显存等比例缩小。这里采用行向量右乘约定，增量为 AB；原论文常用的列向量记法写作 BA。[LoRA 原论文](https://arxiv.org/abs/2106.09685)。

## 7. 自测与实践验收

<details>
<summary>为什么勾选因果 mask 后，Query A 的输出直接等于 V_A？</summary>

A 只允许读自己。允许位置只有一个，其 softmax 权重为 1；B/C 权重为 0，因此加权和恰好为 V_A。这个性质来自可见性规则，不证明模型认为 A 最重要。

</details>

<details>
<summary>为什么输出特征宽度为 2，不能据此说机器人只有两个自由度？</summary>

2 是本例 Value 的宽度。真实系统还可以把这些特征交给输出投影、动作专家或其他模块，产生任意受合同约束的动作维度。特征宽度、动作维度和机械自由度属于不同视角。

</details>

实践：不用界面，先手算 Query A 的一行；再独立改写一个无效 mask 测试，解释全禁读为什么需要拒绝或明确处理。将自己的推导与[源码](javascripts/vla-attention.js)及[数值回归](../tests/interactive/vla-attention.test.cjs)对照；这些检查验证教学算式，不证明真实 VLA 的内部解释或任务成功。
