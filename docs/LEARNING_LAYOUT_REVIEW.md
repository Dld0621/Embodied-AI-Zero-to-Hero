## 学习结构

首页先选择当前要做的事，再按能力顺序进入课程。顶部导航从 15 个并列入口重组为六区：学习中心、基础与图解、交互实验、工程实践、专项与科研、评估与资料。现有原课程、英文版本、实验室和实践验收保留。

| 页面层级 | 内容 | 使用方式 |
| --- | --- | --- |
| 学习首页 | 第一次学习入口、三种学习意图、六阶段路线 | 决定这次学什么 |
| 知识目录与 45 个章节页 | 九领域目录、章节目标、前置依赖、按序小节 | 定位缺少的知识 |
| 201 个独立小节 | 原理、算例、图与读图指导、误区、自测 | 一次处理一个概念 |
| 45 篇连续阅读页 | 同章全部小节和完整图文 | 连续复习或打印 |
| 原课程与交互实验 | 实践任务、输入输出与证据要求 | 用练习验证理解 |

201 幅概念图各保留桌面和窄屏两版，共 402 个本地 SVG。原章节 URL 和知识点锚点继续有效；旧锚点现在定位到对应小节入口。连续阅读版不重复进入搜索结果，独立小节仍可全文搜索。

## 阅读界面

正文限制阅读宽度、增加行距，并提供三档字号和可恢复的专注阅读。小节有当前位置、前置知识提示、上一节/下一节导航；答案、作图数据和深入来源按需展开，正文不依赖脚本显示。

手动“记住本节”只保存一条本浏览器书签，首页可继续或清除。字号和专注设置也只保存在本地；无分析上报，不写入学习验收。浏览器禁止存储时会提示失败。中文微课和英文原课程的语言范围保持明确，不把中文内容标成已完成英文翻译。

## 验证边界

本轮没有进行真实浏览器交互、截图或读者可用性测试。移动端、放大字体、暗色模式、键盘操作和专注状态恢复已作源代码适配，但不能据此宣称真实浏览器视觉验收通过。没有重新训练模型，没有连接真机，也没有把 PR 更新描述为已合并到 master。

另由子代理完整静态审查阅读外壳的 JavaScript、CSS 和模板，未发现确定的高/中优先级阅读阻断。保留一项低优先级维护风险：本地书签验证格式但不验证未来重命名后的目标仍存在；课程路径变更时应保留重定向或迁移书签，用户也可在首页清除旧书签。这不是浏览器或辅助技术实测。

## 维护入口

小节与图修改作者 JSON 后运行 `scripts/build_knowledge_atlas.py`；首页修改 `scripts/build_learning_home.py` 或知识清单后再生成。`--check` 用于发现生成物过期。阅读外壳由本地模板、CSS 和 JavaScript 维护，严格构建会执行图谱与学习布局检查。
