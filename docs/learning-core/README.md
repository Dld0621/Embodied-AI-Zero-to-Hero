# 从机器学习到具身策略：七章桥梁课程

先理解整条闭环：**采集经历 → 划分数据 → 表征观测 → 学习策略 → 执行动作 → 检查失败 → 改进数据与模型**。会背网络结构，不等于能完成这条闭环。

这组补充课程把原有基础课中跨度较大的部分铺开，不替代原有 45 个知识节点。目标是帮助你读懂训练代码、排查学习失败、设计可信实验；完成阅读本身不是“成为专家”的证明。

## 学习节奏：每次只完成一个小闭环

每章按“术语 → 图解 → 算例 → 易错点 → 自测 → 实践”组织。首次学习可以分成两次：先花 30–45 分钟理解与手算，再用一次学习时段完成实践。时间只是建议，不是能力门槛。

先修缺口请回到 [Python](../foundations/01-python-for-robotics.md)、[线性代数](../foundations/02-linear-algebra.md) 与 [概率基础](../foundations/11-probability-and-optimization.md)。不要求先安装 GPU、机器人驱动或下载大模型。

## 一个不需要 GPU 的实验入口

在仓库根目录、安装 NumPy 后运行：

```bash
python examples/learning_core_lab.py --json
```

源码：[离线学习实验](../../examples/learning_core_lab.py)。四个实验分别检查数据隔离、手写反传、分布偏移和多峰动作。输出是本次运行的数值，不是预填的“成功率”。

| 实验 | 操作 | 你要解释什么 |
| --- | --- | --- |
| 数据隔离 | 查看训练均值与留出数据均值 | 为什么不能让测试数据参与归一化 |
| 反向传播 | 对照解析梯度与有限差分，再看 loss | 梯度正确与模型泛化为何是两件事 |
| 分布偏移 | 对照扰动后的 BC 与聚合数据策略 | 哪些状态从未在原示教中出现 |
| 多峰动作 | 查看左右动作的均值与碰撞判据 | 为什么平均动作可能不属于任何可行模式 |

## 从读懂到研究：四道验收门

1. **解释**：不看答案，说清一个概念的输入、输出和假设。
2. **实现**：跑通小实验，改一个条件并先预测结果。
3. **验证**：在未参与调参的数据或环境中检验，报告失败而不只展示成功视频。
4. **研究**：设定可证伪问题、公平基线、重复试验与消融；证明贡献来自提出的改动。
